Node: The kernel modules can be overwritten here, maybe then  sudo ./apply_binaries.sh execute before.
      The apply_binaries.sh script is a central tool from NVIDIA to make the root file system (rootfs/) 
      of your Jetson system fully operational. It adds firmware, kernel modules, headers, tools and configuration files.
      
      - unpacking and installing NVIDIA-specific .tbz2 archives into the rootfs
      - setting kernel header symlinks
      - updating initrd (initial RAM disk)
      - install extlinux.conf
      - add system groups
