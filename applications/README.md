# Anwendungen

Hier können abgegrenzte Labor-/Demo-/Kundenanwendungen liegen, wenn sinnvoll; eigenständige Kunden-Repos sind ausdrücklich möglich.

Eine Anwendung referenziert die verwendete Plattform-Baseline, Module, Runtime-Profile und Deployment-Konfiguration, ohne Betriebssystem-/Kerneldateien hineinzukopieren.
