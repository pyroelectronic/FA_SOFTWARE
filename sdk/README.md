# FA SDK — wachsender Baukasten

`modules/` = wiederverwendbare Bibliotheken/Adapter; `examples/` = minimale lauffähige Demonstrationen; `templates/` = vollständige Projektgerüste. Ein Compose-Rezept kann referenziert sein, gehört aber nicht automatisch zu jedem Modul.

Nur wiederverwendbare Teile nach realen Anwendungstests übernehmen; Studentenarchive sind zunächst **Referenz**, keine freigegebene API.
