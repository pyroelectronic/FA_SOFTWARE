# Laborprofil

Die aktuelle Teilimplementierung `labor` liegt im [zentralen Gateway-Installer](../../../platform/gateway/provisioning/install.sh): Projektverzeichnisse und eine persistente Node-RED-Runtime. Der vollständige Laborumfang ist noch nicht implementiert; hier wird kein zweiter Installer und keine zusätzliche Compose-Struktur angelegt.

Zielumfang und Entwicklungspakete stehen im [Installationskonzept](../../../platform/gateway/provisioning/INSTALLATIONSKONZEPT.md), tatsächliche Hardwaremeldungen im [Projektstatus](../../../docs/PROJEKTSTATUS.md). Das gemeinsame Laborkonto und die getrennten Projekt-/Runtime-Pfade bleiben erhalten.
